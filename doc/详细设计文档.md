# 车音工坊 - 详细设计文档

## 1. 项目概述

### 1.1 项目背景
「车音工坊」是一款面向汽车音响改装/调音技师的副业预约管理小程序。技师可以在小程序上展示自己的服务项目，客户可以自助浏览、选择服务并预约时间段，技师只需在后台确认预约即可。

### 1.2 核心价值
- **技师端**：零维护成本，无需人工回复，客户自助预约
- **客户端**：透明化服务和价格，自主选择时间段，减少沟通成本

### 1.3 技术栈
| 类别 | 技术 | 版本 |
|------|------|------|
| 前端框架 | Taro | 4.x |
| UI 框架 | React | 18.x |
| 开发语言 | TypeScript | 5.x |
| 样式方案 | SCSS Modules | - |
| 状态管理 | React Hooks | - |
| 后端服务 | 微信云开发 | - |
| 数据库 | 云数据库 | - |
| 云函数 | 云函数 | - |

## 4. 云函数设计

### 4.1 login（用户登录）
- **功能**：获取用户 openid，创建或更新用户记录
- **入参**：`{ nickname, avatar }`
- **出参**：`{ _id, _openid, nickname, avatar, phone, isAdmin }`
- **逻辑**：
  1. 通过 `cloud.getWXContext()` 获取 openid
  2. 查询 users 表是否存在该用户
  3. 存在则更新昵称和头像
  4. 不存在则创建新用户记录

### 4.2 getServices（获取服务列表）
- **功能**：获取所有启用的服务
- **入参**：`{ category }`（可选）
- **出参**：`ServiceItem[]`
- **逻辑**：
  1. 查询 services 表，条件：`isActive = true`
  2. 如果传入 category，增加分类过滤
  3. 按 sortOrder 升序排序

### 4.3 manageService（管理服务）
- **功能**：增删改服务项目
- **入参**：`{ action, serviceId, ...data }`
  - action: 'create' | 'update' | 'delete'
- **出参**：`{ _id }`
- **逻辑**：
  1. 验证管理员权限
  2. 根据 action 执行对应操作
  3. delete 操作为软删除（设置 isActive = false）

### 4.4 getTimeSlots（获取时段）
- **功能**：获取指定日期的可预约时段
- **入参**：`{ date }`（可选）
- **出参**：`TimeSlot[]`
- **逻辑**：
  1. 查询 time_slots 表
  2. 如果传入 date，按日期过滤
  3. 按 startTime 升序排序

### 4.5 manageTimeSlot（管理时段）
- **功能**：创建或更新时段
- **入参**：`{ action, slotId, ...data }`
- **出参**：`{ _id }`
- **逻辑**：
  1. 验证管理员权限
  2. 根据 action 执行创建或更新

### 4.6 createAppointment（创建预约）
- **功能**：创建新的预约记录
- **入参**：`{ serviceId, serviceName, servicePrice, date, timeSlot, customerName, phone, carModel, remark }`
- **出参**：`{ _id }`
- **逻辑**：
  1. 获取用户 openid
  2. 创建预约记录，状态为 'pending'

### 4.7 getAppointments（获取预约列表）
- **功能**：获取预约列表（用户看自己的，管理员看所有）
- **入参**：`{ status, isAdmin }`（可选）
- **出参**：`Appointment[]`
- **逻辑**：
  1. 检查用户是否管理员
  2. 管理员查询所有预约
  3. 普通用户只查询自己的预约
  4. 可选按 status 过滤
  5. 按 createTime 降序排序

### 4.8 updateAppointment（更新预约状态）
- **功能**：更新预约状态
- **入参**：`{ appointmentId, status }`
- **出参**：`{ _id, status }`
- **逻辑**：
  1. 更新指定预约的状态
  2. 记录 updateTime

### 4.9 checkAdmin（检查管理员）
- **功能**：检查当前用户是否为管理员
- **入参**：无
- **出参**：`{ isAdmin }`
- **逻辑**：
  1. 查询 users 表
  2. 返回 isAdmin 字段

### 4.10 bindAdmin（绑定管理员）
- **功能**：将当前用户设为管理员
- **入参**：无
- **出参**：`{ success }`
- **逻辑**：
  1. 更新 users 表，设置 isAdmin = true

## 5. 前端页面设计

### 5.1 页面结构

#### TabBar 页面（3个）
1. **首页 (home)** - 服务浏览入口
2. **预约 (booking)** - 三步式预约流程
3. **我的 (mine)** - 个人中心 + 管理入口

#### 二级页面（5个）
4. **服务详情 (serviceDetail)** - 服务详细介绍
5. **管理后台 (admin)** - 管理功能入口
6. **服务管理 (adminServices)** - 增删改服务
7. **时段管理 (adminTimeSlots)** - 管理可预约时段
8. **预约管理 (adminAppointments)** - 确认/完成预约

### 5.2 页面详细设计

#### 5.2.1 首页 (home)

**功能**：
- 顶部 Hero Banner 展示品牌信息
- 分类导航（全部/调音/改装）
- 服务列表展示

**数据流**：
1. 页面加载时调用 `getServices` 获取服务列表
2. 点击分类切换时重新调用 `getServices({ category })`
3. 点击服务卡片跳转到服务详情页

#### 5.2.2 预约页 (booking)

**功能**：
- 步骤指示器（选择服务 → 选择时间 → 填写信息）
- 服务网格选择
- 日期横向滚动选择
- 时段网格选择
- 表单填写（姓名、手机、车型、备注）

**数据流**：
1. 页面加载时调用 `getServices` 获取服务列表
2. 选择日期后调用 `getTimeSlots({ date })` 获取可用时段
3. 提交时调用 `createAppointment` 创建预约
4. 成功后跳转到「我的」页面

#### 5.2.3 我的页 (mine)

**功能**：
- 用户信息卡片（已登录）/ 登录按钮（未登录）
- 功能入口（管理后台，仅管理员可见）
- 我的预约列表
- 退出登录

**数据流**：
1. 页面加载时检查本地存储的用户信息
2. 已登录则调用 `getAppointments` 获取预约列表
3. 调用 `checkAdmin` 检查管理员身份
4. 点击登录时调用 `getUserProfile` + `login`

#### 5.2.4 服务详情页 (serviceDetail)

**功能**：
- 服务图片展示
- 服务信息（名称、价格、分类、时长、描述）
- 立即预约按钮

**数据流**：
1. 通过路由参数获取服务 ID
2. 调用 `getServices` 并筛选出对应服务

#### 5.2.5 管理后台首页 (admin)

**功能**：
- 顶部管理后台标题
- 统计卡片（待确认数、今日预约数）
- 功能入口网格（预约管理、服务管理、时段管理）

**数据流**：
1. 调用 `getAppointments` 获取所有预约
2. 计算待确认数和今日预约数

#### 5.2.6 服务管理页 (adminServices)

**功能**：
- 服务列表展示
- 添加/编辑/删除服务
- 底部弹窗表单

**数据流**：
1. 调用 `getServices` 获取服务列表
2. 添加/编辑时调用 `manageService({ action, ...data })`
3. 删除时调用 `manageService({ action: 'delete', serviceId })`

#### 5.2.7 时段管理页 (adminTimeSlots)

**功能**：
- 日期横向滚动选择
- 时段列表展示（开放/关闭状态）
- 添加时段
- 点击切换时段开放状态

**数据流**：
1. 选择日期后调用 `getTimeSlots({ date })`
2. 添加时段调用 `manageTimeSlot({ action: 'create', ...data })`
3. 切换状态调用 `manageTimeSlot({ action: 'update', slotId, isAvailable })`

#### 5.2.8 预约管理页 (adminAppointments)

**功能**：
- 状态筛选栏（全部/待确认/已确认/已完成/已取消）
- 预约列表展示
- 确认/完成操作按钮

**数据流**：
1. 调用 `getAppointments({ status })` 获取预约列表
2. 确认时调用 `updateAppointment({ appointmentId, status: 'confirmed' })`
3. 完成时调用 `updateAppointment({ appointmentId, status: 'completed' })`

## 6. 样式设计

- 全局变量定义在 `styles/variables.scss`

## 7. 状态管理

### 7.1 全局状态
- 用户信息存储在 `Taro.getStorageSync('userInfo')`
- 通过 `useUser` Hook 管理用户状态

### 7.2 页面状态
- 每个页面使用 `useState` 管理局部状态
- 使用 `useCallback` 缓存函数引用
- 使用 `useEffect` 处理副作用

---

## 8. 错误处理

### 8.1 前端错误处理
- 所有云函数调用使用 try-catch 包裹
- 错误时显示 Toast 提示
- 控制台打印错误日志

### 8.2 后端错误处理
- 云函数统一返回格式：`{ code, message, data }`
- 成功：code = 0
- 失败：code = -1（服务异常）或 code = -2（权限不足）

---

## 9. 安全设计

### 9.1 权限控制
- 用户登录通过微信授权，获取 openid
- 管理员权限存储在 users 表的 isAdmin 字段
- 云函数中验证管理员权限后才允许操作

### 9.2 数据安全
- 用户只能查看和操作自己的预约
- 管理员可以查看和操作所有预约
- 敏感操作（删除、状态变更）需要管理员权限

## 10. 性能优化
